# مراجعة كلمات البرتغالية

تطبيق ويب (يعمل على الجوال) لمراجعة كلمات منهج دولينغو البرتغالي بنمط "طابق الأزواج".

- اختر الدرس الذي وصلت إليه (1–311) وستظهر كلمات عشوائية من كل الدروس حتى الدرس المختار.
- الأولوية: الكلمات التي أخطأت فيها ← الكلمات التي لم تُعرض بعد ← الأقل مراجعة/الأقدم.
- التقدّم محفوظ في `localStorage` للمتصفح. بلا وقت ولا مسابقة؛ كل 6 جولات استراحة قصيرة.

تحديث الكلمات: `python3 tools/build_data.py path/to/duolingo_portuguese_words.xlsx` ثم يُنتج `data.js`.
